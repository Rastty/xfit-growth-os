# AGENTS.md — Xfit Growth OS (independent of Prometheus)

## Mission and owner directive (2026-10-30)

Build the best trustworthy Czech fitness, supplement and nutrition decision website for beginners and active people. **Help the reader first; affiliate revenue second.** Never optimize for article quantity, commits or superficial activity. A user should return because Xfit genuinely solves practical problems.

This repo is independent: do not read, modify, dispatch or share credentials with Prometheus or any of its sites.

## One autonomous development cycle (if a genuine AI coding agent is attached)

1. Read this file, docs/AUTONOMOUS_OPERATIONS.md, docs/EDITORIAL_STANDARD.md, docs/GROWTH_PLAN_AFTER_EXPORTS.md, current open issues/PRs and GitHub Actions.
2. Inspect real WP/analytics/affiliate evidence. Select the single highest user-impact defect or decision tool; do not choose filler work.
3. Implement a substantial, bounded improvement (code + content if appropriate) with tests and a rollback plan. Prefer a great working problem solver over another nearly identical article.
4. Execute unit tests and real mobile Chrome QA. New content must pass scripts/xfit_editorial_gate.py. Verify accessibility, responsive layout, truthful products and scientifically supported information.
5. When correctly authorized by repository workflows, release through native WP REST with authenticated readback and public URL verification. Never equate commit/CI/merge to live status.
6. Measure impact when attributable; otherwise write UNKNOWN, not fabricated figures. Document specific next step. GitHub status issue #1 is the separate report channel.
7. Continue the next cycle without owner ping for routine work, but **do not pretend a scheduled AI developer exists** unless a real automation, Copilot agent or other authorized worker is configured and running.

## Rank work by concrete impact

1. Visitor journey: question → transparent decision → clear options / when not to buy → trustworthy next action.
2. Mobile UX, content usability and visual hierarchy before bulk pages.
3. Repair relevant, existing landing pages based on GA4 source/medium, GSC and onsite behavior. No SEO gain claims based solely on crawl or article count.
4. Verified products and affiliate routing; lead with limitations, not marketing.
5. Archive cleanup in focused waves; trash/unpublish only demonstrably useless/out-of-scope URLs with immutable allowlist, backup, rollback and readback. Redirect only when user intent legitimately matches; never blanket redirect to homepage.
6. Fitness/nutrition education where evidence and reader demand justify depth.

## Non-negotiable editorial standards

- No fabricated hands-on tests, expert biographies, customer testimonials, clinical effects, prices, stock, reviews or sales.
- Important scientific claims need independent scientific or governmental sources and appropriate context. Check EU nutrition/health-claim requirements.
- Avoid promises to treat conditions, miracle fat loss or hormone manipulation.
- Always include “no supplement necessary” pathway when relevant.
- Native Czech, concise above-the-fold verdict, accessible semantic HTML, responsive real mobile browser check, no duplicated headings or repeated content.
- Product rankings must document exact scoring criteria, coverage and limitations; affiliate commission must not affect rank. No Heureka CPC deep links masquerading as Affial.
- Do not send quiz answers or sensitive health details into analytics.
