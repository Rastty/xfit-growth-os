# Xfit Growth OS

Samostatný vývojový a publikační systém pro https://xfit.cz/.

**Mimo Prometheus. Bez WPVibe.**

Stav: repo inicializováno. Pro automatické publikování chybí ověřené WordPress REST API přihlašování a schválené affiliate feedy. Commity nejsou důkazem publikace na živém webu.

Princip: audit → priorita → implementace → test → publish → ověření veřejné URL → měření.

Žádná citlivá hesla nebo tokeny do repozitáře ani do chatu.
